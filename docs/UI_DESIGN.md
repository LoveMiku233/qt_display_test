## 新增页面详细设计

### 1. 设备组管理页面 (group_page.ui)

```
┌─────────────────────────────────────────────────────────────────┐
│  设备组管理                                                      │
├─────────────────────────────────┬───────────────────────────────┤
│  ┌───────────────────────────┐  │  ┌─────────────────────────┐  │
│  │  组列表                   │  │  │  组内设备               │  │
│  ├───────────────────────────┤  │  ├─────────────────────────┤  │
│  │ ID:1 - 主控组 (3个设备)   │  │  │ 设备节点: 1             │  │
│  │ ID:2 - 备用组 (1个设备)   │  │  │ 设备节点: 2             │  │
│  │                           │  │  │ 设备节点: 3             │  │
│  │                           │  │  │                         │  │
│  │                           │  │  │                         │  │
│  │                           │  │  │                         │  │
│  └───────────────────────────┘  │  └─────────────────────────┘  │
│  [创建组] [删除组] [刷新]       │  [添加设备] [移除设备]        │
└─────────────────────────────────┴───────────────────────────────┘
│ 状态: 共 2 个组                                                  │
└─────────────────────────────────────────────────────────────────┘
```

**功能说明:**
- **左侧**: 显示所有设备组列表
  - 点击组可以查看组内设备
  - 创建组按钮: 弹出对话框输入组ID和名称
  - 删除组按钮: 删除当前选中的组
  - 刷新按钮: 重新加载组列表

- **右侧**: 显示选中组的设备列表
  - 添加设备按钮: 弹出对话框输入设备节点ID
  - 移除设备按钮: 从组中移除选中的设备

## 响应式布局说明

所有页面使用Qt的布局管理器:
- **QVBoxLayout**: 垂直布局
- **QHBoxLayout**: 水平布局
- **QFormLayout**: 表单布局
- **QGridLayout**: 网格布局

优点:
- 自动适应窗口大小变化
- 保持界面元素的比例关系
- 在不同分辨率下表现一致

## 样式和主题

使用Qt Fusion样式:
```cpp
QApplication::setStyle(QStyleFactory::create("Fusion"));
```

特点:
- 跨平台一致的外观
- 现代化的界面风格
- 良好的可读性

## 用户反馈机制

1. **状态标签**: 每个页面底部显示操作状态
2. **消息框**: 重要操作使用QMessageBox提示
3. **输入对话框**: 使用QInputDialog收集用户输入
4. **确认对话框**: 危险操作使用QMessageBox::question确认

## 键盘快捷键建议 (未来实现)

- `Ctrl+G`: 快速跳转到设备组页面
- `Ctrl+A`: 快速跳转到自动控制页面
- `Ctrl+S`: 保存设置
- `F5`: 刷新当前页面
- `Esc`: 停止自动控制

## 无障碍支持

所有按钮和控件都有明确的文本标签，支持:
- 屏幕阅读器
- 键盘导航
- Tab顺序合理
